Pemasangan Bridge (bila bridge.html belum ada)

Aplikasi membaca data lewat bridge.html yang dipasang pada folder instalasi Dapodik. Bila bridge belum ada, unduh file pemasang (.bat) di bawah, lalu klik kanan → Run as administrator. File .bat akan menuliskan bridge.html ke folder tujuan secara otomatis.

Setelah terpasang, kembali ke pengaturan koneksi lalu klik "Periksa Koneksi". Jika Dapodik diinstal di lokasi lain, sesuaikan folder tujuan di atas.
